## Context 是 Claude 的工作記憶

<div class="cg">
<div class="cc" data-motion="fade-in"><h3>什麼算進去</h3><p>系統提示、所有訊息（含工具結果、圖片、文件）、工具定義，以及這一輪產生的輸出，包含思考內容。</p></div>
<div class="cc" data-motion="fade-in"><h3>視窗有多大</h3><p>官方文件列出的 1M token 模型包括 Opus 5.5、Sonnet 5.5、Haiku 5.5 等；其他模型為 200k token。</p></div>
<div class="cc" data-motion="fade-in"><h3>不是越多越好</h3><p>內容越多，準確度與召回會下降，官方稱為 context rot。所以要挑選放進視窗的內容。</p></div>
<div class="cc" data-motion="fade-in"><h3>怎麼管理</h3><p>伺服器端 compaction（beta）會摘要較早的對話；也可以清除舊的工具結果或舊的思考區塊。快取的前綴仍佔視窗，改變的是計費。</p></div>
</div>

<div class="src" data-motion="fade-in">來源：Anthropic 官方文件 platform.claude.com/docs/en/build-with-claude/context-windows。上方內容為官方英文說明的中文譯寫。計價方面，官方提到 Haiku 5.5 超過 100,000 token 的 prompt 費用較高。</div>
