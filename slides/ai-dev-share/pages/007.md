<div class="cap">費用 = token 數 × 輸入單價。單價來源：claude.com/pricing（Haiku 5.5 取 100K tokens 以下）。effort 對 token 數的倍率為示意，非實際用量。</div>

<script>
(function () {
  var models = [
    { name: 'Haiku 5.5', price: 0.10 },
    { name: 'Sonnet 5.5', price: 2 },
    { name: 'Opus 5.5', price: 4 }
  ];
  // effort 倍率為示意值，用來說明 effort 會增加 token 數
  var efforts = [
    { name: 'low', mult: 1 },
    { name: 'medium', mult: 2 },
    { name: 'high', mult: 3 },
    { name: 'max', mult: 4 }
  ];
  var maxCost = models[models.length - 1].price * efforts[efforts.length - 1].mult;
  var mRange = document.getElementById('demo-model');
  if (!mRange) return;
  var eRange = document.getElementById('demo-effort');
  var mName = document.getElementById('demo-model-name');
  var eName = document.getElementById('demo-effort-name');
  var cost = document.getElementById('demo-cost');

  function show(mi, ei) {
    mRange.value = mi;
    eRange.value = ei;
    mName.textContent = models[mi].name;
    eName.textContent = efforts[ei].name;
    cost.style.width = (models[mi].price * efforts[ei].mult / maxCost * 100).toFixed(1) + '%';
  }

  function randomize() {
    show(Math.floor(Math.random() * models.length), Math.floor(Math.random() * efforts.length));
  }

  randomize();
  setInterval(randomize, 1400);
})();
</script>

## 動效

- 眉標：fade-up，y 為 12px
- 標題：wipe，時長 mid
- 模型與 effort 兩個 range slider：每 1.4 秒隨機跳到一個檔位（由腳本控制，不可拖曳）
- 費用 bar：寬度依目前模型單價與 effort 倍率變化，以 0.6 秒平滑過渡
- mark：共用元素，與第 6 頁標題中「Token」字樣的 mark 相同 id，翻頁時從第 6 頁的「Token」飛到「token 費用」標籤後面，成為底框；標籤文字為白色
- cost：共用元素，放在費用 bar 的右端，下一頁若有相同 id 的元素，翻頁時會從這裡飛過去
